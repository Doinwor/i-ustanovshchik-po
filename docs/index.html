Системные требования

🪟

Windows 10 / 11

Любая актуальная редакция. Установка локальная, права администратора подскажет сам winget.

📥

winget

Приложение App Installer из Microsoft Store. Проверяется при старте: winget --version.

☕

Java уже внутри

EXE-сборка включает рантайм Java 21 — устанавливать ничего не нужно. Для портативного .jar понадобится JRE 21.

Команда под капотом

winget install --id <ID> -e --source winget ^
      --accept-package-agreements --accept-source-agreements ^
      --disable-interactivity [--silent]

--source winget указан намеренно: без него winget опрашивает ещё и msstore, который часто падает с ошибкой сертификата 0x8A15005E. Если пакет уже установлен, winget возвращает ненулевой код — приложение показывает статус «Уже установлено» вместо ошибки.

Частые вопросы

Коротко о том, что спрашивают чаще всего.

Нужен ли интернет?

Да. winget скачивает пакеты из интернета, а иконки программ подгружаются по домену и кэшируются в папке icons — повторные запуски работают без сети.

А если программа уже установлена?

winget вернёт ненулевой код, приложение это распознаёт и показывает статус «Уже установлено» вместо «Ошибка».

Почему установка идёт только с --source winget?

Без этого флага winget опрашивает ещё и источник msstore, который часто падает с ошибкой сертификата 0x8A15005E и срывает установку.

Как добавить свою программу в список?

Откройте apps.json и добавьте объект с полями id, name, category, description и domain. Точный id ищется командой winget search название.

Куда пишется журнал?

Вывод winget дублируется в окне и в файл installer.log рядом с программой.

Что делает «Тихая установка»?

Добавляет к команде флаг --silent: установщики не показывают окна и вопросы.

Готовы навести порядок в программах?

Один файл, одна кнопка — и компьютер настроен.
